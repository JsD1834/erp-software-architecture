# 1. Introducción y Objetivos

## 1.1 Objetivo del Sistema

El sistema ERP tiene como objetivo integrar y optimizar los procesos operativos de la organización mediante una plataforma centralizada que facilite la gestión de la información, automatice las operaciones del negocio y apoye la toma de decisiones.

Dentro del ERP, el Módulo de Compras permite administrar de forma eficiente el ciclo de abastecimiento, desde el registro de entregas y despachos hasta la actualización del inventario, garantizando la trazabilidad de las operaciones y la disponibilidad de información confiable para los diferentes actores de la organización.

---

## 1.2 Objetivos del Módulo de Compras

- Centralizar la gestión de las operaciones de compras.
- Registrar y controlar las entregas y despachos de mercancía.
- Mantener actualizado el inventario de forma automática.
- Proporcionar trazabilidad mediante un sistema de auditoría.
- Facilitar el seguimiento de indicadores mediante un dashboard.
- Mejorar la eficiencia operativa reduciendo errores manuales.

---

## 1.3 Requisitos de Negocio

### RN01. Gestión de Entregas y Despachos

El sistema debe permitir crear, consultar, actualizar y gestionar los movimientos de entrega y despacho asociados al proceso de compras.

### RN02. Gestión de Errores

El sistema debe detectar, registrar y notificar los errores que se presenten durante las operaciones del módulo para facilitar su corrección.

### RN03. Historial de Cambios

El sistema debe registrar todas las modificaciones realizadas sobre la información del módulo de compras, incluyendo el usuario responsable, la fecha y la acción ejecutada.

### RN04. Actualización Automática del Inventario

Cada entrega o despacho confirmado debe actualizar automáticamente las existencias del inventario, garantizando la consistencia de la información.

### RN05. Dashboard de Compras

El sistema debe proporcionar un tablero de control con indicadores e información relevante sobre las operaciones de compras para apoyar la toma de decisiones.
