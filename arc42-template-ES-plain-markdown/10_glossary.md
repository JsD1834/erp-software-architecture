# 10. Glosario

| Término | Definición |
|----------|------------|
| **ERP (Enterprise Resource Planning)** | Sistema de planificación de recursos empresariales que integra y centraliza los procesos operativos de una organización. |
| **Módulo de Compras** | Componente del ERP encargado de gestionar el proceso de adquisición de bienes, incluyendo entregas, despachos y actualización del inventario. |
| **Producto** | Bien físico que la empresa compra, almacena y administra dentro del inventario. |
| **Proveedor** | Persona o empresa que suministra productos o servicios a la organización. |
| **Orden de Compra** | Documento que formaliza la solicitud de adquisición de productos o servicios a un proveedor. |
| **Entrega** | Registro de la recepción de mercancía proveniente de un proveedor como resultado de una orden de compra. |
| **Despacho** | Movimiento de salida de productos desde el inventario hacia otro almacén, sucursal o proceso interno. |
| **Inventario** | Conjunto de productos disponibles y registrados por la organización, incluyendo sus cantidades y ubicación. |
| **Stock** | Cantidad disponible de un producto en el inventario en un momento determinado. |
| **Movimiento de Inventario** | Operación que modifica las existencias de un producto, ya sea por una entrada (entrega) o una salida (despacho). |
| **Auditoría** | Registro de las acciones realizadas por los usuarios sobre el sistema, permitiendo conocer quién realizó un cambio, cuándo lo hizo y qué información fue modificada. |
| **Dashboard** | Panel de control que presenta indicadores, métricas y gráficos para apoyar el monitoreo y la toma de decisiones. |
| **CRUD** | Conjunto de operaciones básicas sobre la información: Crear (Create), Consultar (Read), Actualizar (Update) y Eliminar (Delete). |
| **API REST** | Interfaz de programación que permite la comunicación entre el frontend y el backend mediante solicitudes HTTP. |
| **SPA (Single Page Application)** | Aplicación web que carga una única página y actualiza dinámicamente su contenido sin recargar completamente el navegador. |
| **ASP.NET Core** | Framework utilizado para desarrollar la API REST del backend del sistema ERP. |
| **Angular** | Framework utilizado para desarrollar la interfaz web del sistema como una Single Page Application (SPA). |
| **PostgreSQL** | Sistema gestor de bases de datos relacional utilizado para almacenar la información del ERP. |
